## 预算估算

以下为**规划区间，不是服务商实时报价**，按美元估算，未含税和汇率变化。下单时查看官网当前价格、首年促销与续费价格。主机可在 [DigitalOcean](https://www.digitalocean.com/pricing/droplets)、[Hetzner](https://www.hetzner.com/cloud/) 或合适的托管 WordPress 服务商比较；选择靠近主要客户且可合规经营的地区。

| 项目 | 规划区间 | 说明 |
|---|---:|---|
| 域名 | 10–40 USD/年 | 特殊后缀/溢价域名另算 |
| 生产主机 | 20–80 USD/月 | 小型商城起步；托管服务可能更高 |
| 预发布 | 0–30 USD/月 | 同机隔离副本或独立实例 |
| 多语言插件 | 100–250 USD/年预留 | 以 [WPML 当前套餐](https://wpml.org/purchase/) 为准；机器翻译用量另算 |
| 邮件 | 0–25 USD/月起 | 按事务邮件量与企业邮箱席位计费 |
| 备份/对象存储 | 5–20 USD/月起 | 数据量、请求和恢复流量另计 |
| CDN/WAF/监控 | 0–30 USD/月起 | 可以从免费层开始，按需求升级 |
| SEO 插件 | 免费版本可起步 | 本项目安装 Yoast 免费版；高级功能按需购买 |
| 支付手续费 | 按交易收取 | 商户地、支付方式、跨境、换汇、退款/拒付均可能影响 |
| 专业翻译、摄影、合规审查 | 单独询价 | 不包含在基础软件预算内 |
| 维护人力 | 单独预算 | 更新、监控、内容、售后、测试与故障恢复 |

不要把预算区间当采购指令。本次没有替你购买域名、主机、许可证，也没有创建支付商户账户。

## 需要业务方提供的内容

### 公司与市场

- 公司法定全称、注册地、地址、客服邮箱与电话、负责人、收款银行。
- 首批销售国家、首选语言、结算/销售币种、B2C/B2B 占比、预期客单价。
- 域名选择、品牌 Logo、品牌故事、摄影及素材授权。

### 每个商品

- SKU、真实名称、分类、长短介绍、真实售价/批发规则、库存、采购交期。
- 至少 4–6 张真实图片、白底主图、使用场景、细节、尺寸示意；有条件提供视频。
- 电机额定功率、峰值功率说明、扭矩、电池电压/容量、充电器、重量、尺寸、承载、轮径、接口等。
- 续航必须附测试条件；认证/检测报告必须与具体型号和销售市场对应。
- 电池运输所需资料、包装、承运渠道、备件供应、安装说明、保修处理方式。
- 改装配件的兼容矩阵：轴宽、安装位、控制器协议、电压、电流、刹车与显示屏接口。
- 整车报价所需字段：配置、数量、目的港、贸易术语、定金/尾款规则、运输限制。

### 店铺运营

- 发货仓库、配送国家与邮编范围、运费、预计时效、跟踪链接、关税承担方式。
- 退货窗口、运费承担、退货地址、损坏/丢件处理、退款方式、质保及维修流程。
- 隐私联系人、数据保留期、Cookie 选择策略、客服响应安排。
- 聊天客服账户与值守安排；如启用机器人，另提供 HTTPS 适配服务、模型账户、产品知识库、受保护的密钥、费用限额及处理商资料。详见 [聊天与机器人接入](10-chat-and-bot.md)。
- 不要通过公开仓库或普通文档提供支付 secret；在网关后台或受控凭据管理器配置。

## 推荐实施顺序

先确认市场和收款主体 → 采购域名/主机/WPML → 部署预发布 → 上架真实英文商品 → 翻译并审核 → 配置物流税费 → 支付沙箱联调 → 全流程验收 → 真实小额支付退款 → 正式开放并允许索引。

主要国家和注册地未确认前，可以继续维护设计与商品内容，但不能宣称某个本地支付方式已经可以正式收款。
